# ADR 0001. Доступ к данным Krisha.kz

- Статус: принято
- Дата: 2026-10-10

## Контекст

Сервису нужны объявления о продаже квартир в Алматы. Основная площадка — Krisha.kz (АО «Колёса»).
Пользовательское соглашение (п. 5.3, 5.5.6, 8.1) запрещает автоматизированный доступ, извлечение и
копирование объявлений без письменного разрешения. Публичного API не найдено. Письменного разрешения
у владельца проекта нет.

## Рассмотренные варианты

1. **Парсинг страниц сайта** — нарушает соглашение; к тому же хрупок и требует обхода антибот-защиты. Отклонено.
2. **Сторонние готовые скрейперы** — тот же правовой риск, перенесённый на третье лицо. Отклонено.
3. **Интерфейс источника + разрешённые способы получения данных** — импорт файлов, на которые есть права,
   синтетика для разработки, адаптер под будущий официальный API. **Принято.**

## Решение

- Интерфейс `ListingSource` (`src/server/sources/types.ts`); конвейер не зависит от конкретного источника.
- `KrishaApiSource` всегда сообщает `NOT_CONNECTED` с причиной и не выполняет запросов к сайту.
- Синтетические данные помечены `isSynthetic`, не смешиваются с реальными, интерфейс показывает баннер.

## Последствия

- Оценки на синтетике проверяют работу системы, но не отражают реальный рынок.
- При получении разрешения/API достаточно реализовать один адаптер (см. docs/data-sources.md).
- Импорт файлов перекладывает ответственность за права на данные на того, кто их загружает, — это указано в
  интерфейсе загрузки.
